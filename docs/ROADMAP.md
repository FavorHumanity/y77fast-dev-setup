# Y77FAST Build-in-Public Tech Series: 12-Week Roadmap

A security-first path from Python to Rust to Solana smart contracts (Rust + Anchor), with TypeScript clients that build on my CISW 400 JavaScript class. About 6–8 hours a week alongside ARC classes and work.

| 4 | Security-First Python: Harden the Digital ID Demo | y77fast-digital-id-demo |

| 12 | Smart-Contract Security & Capstone | y77fast-anchor-learning-log + y77fast-build-in-public-recap |

Weeks 9–12 are education only: devnet with free test tokens, no real funds, no mainnet keys, and nothing that is investment advice.

## Habits every week

- Sign every commit and keep the Verified badge.
- Never commit secrets: `.env` + `.gitignore`, and a `.env.example` with placeholders only.
- Write tests before calling something done. Add a short `SECURITY.md` to each repo.
- Small commits with clear messages (`feat:`, `fix:`, `test:`, `docs:`).
- Fake or sample data only.
